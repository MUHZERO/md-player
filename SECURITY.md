# Security policy

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** form in the repository's Security tab:

`https://github.com/MUHZERO/md-player/security/advisories/new`

Include affected versions, impact, reproduction steps, and a minimal proof of
concept. Do not include real credentials, private media, authorization headers,
or signed production URLs.

General bugs that do not have a security impact belong in the public issue
tracker.
